🛒 Mehrsam Shop
A clean, full-stack e-commerce store built to show how Django and React work together.

🌟 What this project does:
This is a standard shop with everything you need:

Product Flow: Browse items, see details, and add to cart.

Smart Shopping: A functional cart and a smooth checkout process.

Solid Backend: Uses Django to manage users, orders, and products safely.

Fast Frontend: Built with React for a modern, "no-refresh" feeling.

🛠 Tech Stack:
Backend: Django & Django REST Framework (Python).

Frontend: React.js & Vite.

Database: SQLite.

"I built this to master the art of connecting a powerful backend with a fast frontend. It’s not just code; it’s a complete experience." 🚀
